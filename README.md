# Weather App

A simple weather application built using HTML, CSS and JavaScript.

## Features

- Search weather by city name
- Temperature display
- Humidity display
- Wind speed display
- Real-time weather data using OpenWeather API

- HTML
- CSS

- OpenWeather API
